# Scene 2 Property Performance Command Center

## Introduction

With the data ready, Sofia and Marcus open the portfolio dashboard. Group bookings are rising, but room readiness is falling behind. They need to find the properties and room types most likely to feel the squeeze.

Estimated time: 10 minutes.

![Sofia and Marcus review demand growth and room-readiness pressure across the hotel portfolio](images/story-property-performance.png)

![Property Performance Command Center](images/property-performance-command-center.png)

### Objectives

Find a property-performance problem and follow it into guest activity, service operations, forecasts, or the owner review.

## Task 1 Review portfolio KPIs

Start with the portfolio overview before opening the detail.

![Property Performance navigation, story context, and portfolio indicators highlighted](images/portfolio-kpis.png)

1. Select **Property Performance Command Center**.
2. Review the story panel to identify the demand, room-readiness, guest-experience, and revenue pattern under investigation.
3. Review reservations, revenue impact, critical guest issues, room types under review, and recorded AI decisions. Treat **Revenue Impact** as booked reservation value on this dashboard, not posted room revenue from folios.

## Task 2 Review demand activity over time

Compare the long-range demand pattern with the revenue categories affected by it.

![Guest and Demand Signal Velocity controls, one-year chart, and revenue-impact chart highlighted](images/demand-signal-velocity.png)

1. Locate **Guest and Demand Signal Velocity**.
2. Select **1y** to load the full synthetic history in weekly buckets. Use the shorter controls for a recent operating window.
3. Review the chart for sustained increases, recurring spikes, and the latest change in activity.
4. Compare the velocity pattern with **Revenue Impact by Room Type and Revenue Center** to identify the categories that need closer review.

## Task 3 Review high-demand room types

Use the operational-risk table to select the room type, revenue center, or property that needs follow-up.

![Operational-risk table search, columns, and first result highlighted](images/operational-risk-room-types.png)

1. Scroll to **Room Type or Revenue Centers Under Operational Risk Review**.
2. Enter a room type, revenue center, or property in the search field. Use a property chip beside the field when you want to narrow the list further.
3. Compare guest activity, revenue impact, issue severity, and the trend for the filtered results.
4. Select a row to open its capacity and guest details.
