# Scene 4: Person Intelligence

## Introduction

Person Intelligence can bring fictional profiles, biographical wording and photo context into review. Vector similarity helps find candidates; it does not identify a person or decide responsibility.

Estimated Time: 8 minutes

![Conceptual source and comparison boundary](../images/source-review.png)

### Objectives

- Inspect one fictional profile and its source-linked attributes.
- Compare narrative and photo-vector search as distinct inputs.

## Task 1: Review a profile

1. Select **Person Intelligence** and open a fictional profile that is visible to the current persona.
2. Read its descriptive fields and available source references. Distinguish an authored profile from any computed similarity result.

## Task 2: Explore vector comparisons

**Animated pause:** [Similarity is a lead](../powtoons/index.html?story=vector). The final beat connects the teaching example to narrative and supplied-photo comparisons.

1. Show the narrative or bio comparison control, if enabled. Explain that related wording can rank nearby profiles or reports; read the underlying text before discussing a candidate.
2. Show the photo or face-comparison control using only the supplied synthetic photos from the sample package or an existing prepared batch. Record the actual model, threshold and source shown by the interface. A whole-photo similarity result may reflect scene composition; it is not facial identity proof.
3. If the active profile lacks compatible embeddings or a photo set, explain the prerequisite and continue with the conceptual vector tile from Scene 1. Do not invent a match.
