# Scene 5b Using Table AI Assist in Data Studio

## Introduction

**PeakGear** leverages in the built in AI features of Data Sudio to process data. Business analysts and data engineers can users can use Table AI Assist (a feature in Data Studio) to modify tables and data based on suggestion generated by AI. Furthermore, AI supports a user to generate the SQL code to modify data and tables. 

In this scenario, a data engineer is tasked to process incoming social media data. The data received by a social media partner contains duplicate and misleading information. Our data engineer identified a pattern and uses Table AI Assist to create a new table that contains cleansed data. In this specific example, the task requires knowledge of regular expressions and how to apply them in SQL. Table AI Assist helps the user to create the correct regular expression.

## Task 4: Create a new Recipe for BRONZE\_DEMAND\_SIGNALS

  &&

  1. Search for **bronze demand** in the search for.
  2. Click on **New Recipe**

## Task 5: Review the preview data

Lets pause for  minute and explore the data preview. The data displayed is data ingested in the real time demo. The challenge is that it is difficult to map a single record to the actual product that is being discussed on social media. The column **PRODUCT\_HINTS** contains a document containing several SKU IDs and product names. PeakGear's data engineer let us know that the first SKU in the document is the relevant once. Our task is to create a new table with an additional column **SKU\_ID** that contains the identifued SKU_ID from the **PRODUCT\_HINTS** column. 

&&

## Task 6: Edit the Recipe

  &&
  
  Perform the following set of steps to prepare the new recipe:
  
  1. Change **Target Type** to **Create Table**.
  2. Set **Target Name** to **BRONZE\_DEMAND\_SIGNALS\_FIXED**.
  3. Click **Add Step** and select **Add or Replace Column**.
  
  A window opens with the help of OCI GenAI the table and its metadata is analyze.
  

## Task 7: Ask AI to generate SQL

  &&
  
  AI created some suggestions for enhancing the table. Perform the following steps to add the new column **SKU_ID**:
  
  1. In the text box **Ask AI to generate SQL**, paste this question: 
   
   ```text
    <copy>
   extract the first sku inside of " " in the PRODUCT_HINTS column
    </copy>
    ```

  2. Click **Ask AI**
  3. Review the result. The left side of the screen show you the narrated response. On the right side you see the SQL generated by AI.
  4. Ensure that the SQL generated looks like this: *REGEXP_SUBSTR("PRODUCT_HINTS", '"(.*?)"', 1, 1, NULL, 1)*
  5. In case your SQL looks different you can either manually update it or you can try to refine the respone.
  6. Rename the column to **SKU_ID**.
  7. Click **Save**.

## Conclusion: Business Outcome

Batch and file loading gives PeakGear a controlled way to bring source files into the AI Lakehouse. The product master CSV is not the final business product; it is the Bronze starting point that preserves the file as it arrived.

Once the file is in Bronze, the medallion process can make it reusable. Silver processing can standardize categories, validate prices, deduplicate SKUs, enrich product attributes, and connect image metadata. Gold data products can then serve a governed catalog foundation to webshop search, product discovery, operations dashboards, fulfillment decisions, and AI agents.

For PeakGear, this means file-based source data becomes part of the same trusted lakehouse flow as streaming and CDC data. The business avoids one-off file handling and gains a repeatable path from raw product data to operational outcomes.
